Otomasi Penerimaan & Pencatatan

Membangun alur otomatis dari Google Form ke Drive dan Sheets: dokumen masuk, tersimpan di folder yang tepat, dan tercatat di buku agenda digital tanpa diketik ulang.

Metode
Praktikum lab, tutorial berpasangan
Bobot tugas
10%
A

Tujuan Pembelajaran

Setelah sesi ini, Anda mampu membangun sistem penerimaan dokumen dan buku agenda digital yang berjalan otomatis.

  1. Menjelaskan alur otomasi penerimaan dokumen: Form, trigger, skrip, Drive, dan Sheets.
  2. Membuat trigger onFormSubmit yang menjalankan skrip setiap kali Form dikirim.
  3. Menulis skrip yang memindahkan file ke folder arsip dan mencatat agenda surat secara otomatis.
  4. Menyesuaikan alur tersebut dengan studi kasus kelompok Anda.

Prasyarat: akun Google aktif, dasar GAS dari sesi 1 (variabel, fungsi, trigger), dan studi kasus yang sudah dipilih kelompok.

Event object e

Saat trigger menyala, GAS menyerahkan satu objek bernama e ke fungsi Anda. Pada trigger Form, e.response berisi jawaban yang baru dikirim. Objek ini hanya ada ketika trigger yang memanggil fungsi. Jika Anda menekan tombol Run, e bernilai undefined dan muncul error. Jalur uji yang aman disediakan di langkah 6.

Pertanyaan unggah file

Jawaban untuk pertanyaan unggah file berupa daftar ID file Drive (array), jadi ID pertama dibaca dengan [0]. Responden harus login ke akun Google untuk mengunggah file, dan file awalnya tersimpan di Drive pemilik Form.

3. Praktikum: membangun alur langkah demi langkah

Langkah 1. Siapkan Form

Buat Google Form dengan judul "Penerimaan Surat Masuk" dan pertanyaan berikut. Judul pertanyaan harus persis sama dengan yang dipakai di kode.

Judul pertanyaanJenis
Nomor SuratJawaban singkat
PengirimJawaban singkat
PerihalJawaban singkat
Jenis SuratPilihan ganda (mis. Undangan, Permohonan, Pemberitahuan, Lainnya)
Unggah File SuratUpload file (PDF, maksimal 1 file)

Langkah 2. Siapkan buku agenda dan folder arsip

  1. Buat Spreadsheet baru bernama "Buku Agenda Surat Masuk". Ubah nama lembar kerja menjadi Agenda.
  2. Isi baris pertama sebagai judul kolom: No. Agenda, Tanggal Diterima, Nomor Surat, Pengirim, Perihal, Jenis Surat, Tautan File.
  3. Buat folder Drive bernama "Arsip Surat Masuk".
  4. Catat dua ID: ID spreadsheet ada di tautan .../d/ID/edit, dan ID folder ada di tautan .../folders/ID.

Langkah 3. Buka editor skrip dari Form

Di Form, klik menu titik tiga (⋮) lalu pilih Editor skrip (Script editor). Skrip yang dibuat dari sini terikat pada Form tersebut, sehingga FormApp.getActiveForm() bisa dipakai.

Langkah 4. Tulis skrip

Hapus kode bawaan, lalu tempel kode berikut. Ganti kedua ID dengan milik Anda.

// Ganti dengan ID milik Anda
const ID_SPREADSHEET = "ID_SPREADSHEET_AGENDA";
const ID_FOLDER_ARSIP = "ID_FOLDER_ARSIP";

// Mengubah jawaban Form menjadi objek: { "Judul Pertanyaan": jawaban }
function ambilJawaban(response) {
  const hasil = {};
  response.getItemResponses().forEach(function (ir) {
    hasil[ir.getItem().getTitle()] = ir.getResponse();
  });
  return hasil;
}

// Fungsi utama: dijalankan oleh trigger setiap Form dikirim
function catatSuratMasuk(e) {
  const jawaban = ambilJawaban(e.response);

  // 1. Pindahkan file ke folder arsip
  const idFile = jawaban["Unggah File Surat"][0];
  const file = DriveApp.getFileById(idFile);
  file.moveTo(DriveApp.getFolderById(ID_FOLDER_ARSIP));

  // 2. Catat ke buku agenda
  const sheet = SpreadsheetApp.openById(ID_SPREADSHEET).getSheetByName("Agenda");
  const nomorUrut = sheet.getLastRow();   // baris 1 = judul kolom, jadi data pertama bernomor 1
  const nomorAgenda = "SM-" + String(nomorUrut).padStart(3, "0");

  sheet.appendRow([
    nomorAgenda,
    new Date(),
    jawaban["Nomor Surat"],
    jawaban["Pengirim"],
    jawaban["Perihal"],
    jawaban["Jenis Surat"],
    file.getUrl()
  ]);
}

Cara kerjanya: ambilJawaban menyusun semua jawaban menjadi objek sehingga Anda bisa memanggilnya dengan judul pertanyaan. Fungsi catatSuratMasuk lalu memindahkan file, menghitung nomor agenda, dan menambahkan satu baris di Sheets.

Langkah 5. Pasang trigger

  1. Di editor skrip, klik ikon jam Pemicu (Triggers) di sidebar kiri.
  2. Klik Tambahkan Pemicu (Add Trigger).
  3. Pilih fungsi catatSuratMasuk, sumber acara Dari formulir (From form), dan jenis acara Saat formulir dikirim (On form submit).
  4. Simpan. Saat pertama kali, izinkan akses: klik Tinjau izin, pilih akun Anda, lalu setujui. Jika muncul peringatan "aplikasi belum diverifikasi", klik Lanjutan lalu lanjutkan, karena skrip ini milik Anda sendiri.

Langkah 6. Uji coba

Isi dan kirim Form sungguhan satu kali (login akun Google, unggah satu PDF kecil). Lalu periksa: baris baru di Sheets, file pindah ke folder arsip, dan trigger tercatat di Eksekusi (Executions) di sidebar.

Untuk menguji ulang tanpa mengisi Form lagi, tambahkan fungsi ini. Ia mengambil jawaban terakhir dan menyerahkannya seperti yang dilakukan trigger:

function ujiCoba() {
  const semua = FormApp.getActiveForm().getResponses();
  const terakhir = semua[semua.length - 1];
  catatSuratMasuk({ response: terakhir });
}
Catatan: setiap kali ujiCoba dijalankan, satu baris agenda baru ditambahkan lagi. Hapus baris ganda di Sheets setelah pengujian.

Tugas Praktikum Sesi 2

Dikerjakan berpasangan, dikumpulkan sebelum sesi 3.

  1. Bangun alur penerimaan untuk studi kasus Anda. Ubah pertanyaan Form, kolom Sheets, nama folder, dan awalan nomor agenda agar sesuai dengan jenis dokumen studi kasus kelompok (misalnya KT- untuk kontrak).
  2. Uji alurnya dengan minimal tiga kiriman Form yang berbeda dan pastikan semuanya tercatat lengkap.
  3. Beri komentar pada setiap blok kode dengan bahasa Anda sendiri, yang menjelaskan apa yang dilakukannya.
  4. Kumpulkan: tautan Form, tautan Spreadsheet buku agenda (akses lihat), tautan proyek skrip, dan tangkapan layar hasil Sheets serta folder Drive.
