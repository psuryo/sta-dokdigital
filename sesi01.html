Review GAS & Pemetaan Siklus Dokumen

Menyegarkan dasar Google Apps Script, memetakan layanan GAS pada tiap tahap siklus hidup dokumen, dan memilih studi kasus untuk proyek akhir.

Metode
Ceramah interaktif, live coding, diskusi kelompok
Bobot tugas
5%
A

Tujuan Pembelajaran

Setelah sesi ini, Anda mampu mereview konsep dasar GAS dan memetakan otomasi pada tiap tahap siklus dokumen.

  1. Menulis fungsi GAS sederhana dengan variabel, fungsi, dan trigger.
  2. Menjelaskan tahap siklus hidup dokumen digital dan layanan GAS yang mengotomasinya.
  3. Menentukan studi kasus kelompok dan menyusun proposal singkat untuk proyek akhir.

Prasyarat: akun Google aktif dan dasar-dasar GAS dari perkuliahan sebelumnya.

C

Materi Pembelajaran

1. Sintaks dasar GAS

GAS memakai JavaScript, ditambah layanan bawaan Google (DriveApp, SpreadsheetApp, GmailApp, dan lainnya). Buka script.google.com, buat proyek baru, lalu coba setiap contoh di bawah. Lihat hasilnya di Log eksekusi. Berikut sintaks yang paling sering dipakai sepanjang mata kuliah ini.

Peta analogi: dari dunia kearsipan ke kode

Semua konsep di bawah sebenarnya sudah akrab bagi Anda di bidang administrasi perkantoran. Gunakan tabel ini sebagai jembatan sebelum masuk ke sintaksnya.

Konsep GASPadanan di kearsipanContoh
variabelLaci atau map yang diberi label dan bisa diisi dokumenlet jumlah = 12
arrayDaftar baris pada buku agenda["SM-001", "SM-002"]
objekKartu kendali atau formulir dengan kolom nomor, judul, tahun{ nomor: "001", tahun: 2026 }
if / elseAturan disposisi: jika surat penting, teruskan ke pimpinan; jika tidak, arsipkanif (penting) {...}
perulanganMenstempel 100 surat satu per satu dengan cara yang samafor / forEach / while
functionSOP yang ditulis sekali dan dipakai berulangfunction arsipkan() {...}
parameter & returnBahan yang diserahkan ke SOP, dan hasil yang dikembalikanfunction beriNama(unit) { return ... }
triggerAlarm pengingat atau disposisi otomatis yang berjalan tanpa dimintaScriptApp.newTrigger()
try / catchProsedur bila surat yang dicari tidak ditemukan di lemari arsiptry {...} catch (e) {...}

Mulai dengan satu keberhasilan kecil

Sebelum membaca sintaks satu per satu, jalankan fungsi latihan1() pada bagian f dan lihat hasilnya di log. Begitu satu hal berhasil berjalan, kode terasa tidak semenakutkan yang dibayangkan. Ingat juga bahwa error itu hal biasa, bahkan programmer profesional mengalaminya setiap hari. Baca pesan galatnya pelan-pelan, karena biasanya menyebut baris dan penyebab masalahnya.

a. Variabel: const dan let

Variabel menyimpan nilai agar bisa dipakai ulang. Gunakan const untuk nilai yang tidak berubah dan let untuk nilai yang akan diubah. Hindari var, karena cakupannya lebih membingungkan.

const unit = "Sekretariat";   // tetap
let jumlahDokumen = 12;       // bisa diubah
jumlahDokumen = jumlahDokumen + 1;

b. Tipe data

Lima tipe yang paling sering muncul: teks (string), angka (number), benar/salah (boolean), daftar (array), dan objek.

const judul = "Surat Undangan";                    // string
const jumlah = 5;                                  // number
const sudahArsip = false;                          // boolean
const jenis = ["Surat Masuk", "Surat Keluar"];     // array
const dokumen = { nomor: "001", judul: "Undangan", tahun: 2026 };  // objek

c. Array dan objek: mengakses isi

Array dibaca dengan nomor indeks yang dimulai dari 0. Objek dibaca dengan nama properti. Data dari Spreadsheet, Form, dan Drive hampir selalu berbentuk array atau objek.

Logger.log(jenis[0]);          // "Surat Masuk"
Logger.log(jenis.length);      // 2
jenis.push("Notulen");         // tambah di akhir
Logger.log(dokumen.judul);     // "Undangan"
dokumen.status = "Aktif";      // tambah properti baru

d. Operator dan kondisi: if / else

Kondisi memilih tindakan berdasarkan data. Pakai === untuk membandingkan (bukan =, yang berarti mengisi nilai). && berarti "dan", || berarti "atau".

if (jumlah > 10) {
  Logger.log("Banyak");
} else if (jumlah > 0 && jumlah <= 10) {
  Logger.log("Sedikit");
} else {
  Logger.log("Kosong");
}

if (judul === "Surat Undangan" || sudahArsip) {
  Logger.log("Perlu dicek");
}

e. Perulangan: for, forEach, while

Perulangan memproses banyak data sekaligus, misalnya semua file di folder. for cocok bila butuh nomor urut, forEach untuk array, dan while untuk iterator Drive yang memakai hasNext().

for (let i = 0; i < jenis.length; i++) {
  Logger.log((i + 1) + ". " + jenis[i]);
}

jenis.forEach(function (j) {
  Logger.log(j);
});

// pola khas DriveApp
const files = DriveApp.getRootFolder().getFiles();
while (files.hasNext()) {
  Logger.log(files.next().getName());
}

f. Fungsi: function, parameter, return

Fungsi adalah blok kode yang diberi nama agar bisa dipanggil berulang atau dijalankan oleh trigger. Parameter adalah data masukan, dan return mengembalikan hasil. Fungsi yang ada di editor bisa dijalankan langsung lewat tombol Jalankan.

function ringkasan(namaUnit, jumlah) {
  return namaUnit + " memiliki " + jumlah + " dokumen.";
}

function latihan1() {
  Logger.log(ringkasan("Sekretariat", 12));
}

g. Template literal (teks dengan backtick)

Cara menyusun teks yang lebih rapi daripada tanda +. Nilai variabel disisipkan dengan ${...}. Sangat berguna untuk nama file dan isi email.

const nomor = "007";
const nama = `SEK_SuratMasuk_${nomor}`;
Logger.log(nama);   // SEK_SuratMasuk_007

h. Tanggal: new Date() dan Utilities.formatDate()

Tanggal sering dipakai di penamaan file, log agenda, dan masa retensi. formatDate mengubah tanggal menjadi teks dengan format tertentu.

const sekarang = new Date();
const tanggal = Utilities.formatDate(sekarang, "Asia/Jakarta", "yyyyMMdd");
Logger.log(tanggal);   // mis. 20261022

i. Layanan bawaan Google

Ini yang membedakan GAS dari JavaScript biasa: kode dapat langsung mengakses layanan Google. Nama layanan diikuti metode dengan tanda titik.

LayananFungsinyaContoh
DriveAppMengelola file dan folder di DriveDriveApp.getFolderById(id)
SpreadsheetAppMembaca dan menulis Google Sheetssheet.appendRow([...])
FormAppMengakses Google Form dan responsnyaFormApp.openById(id)
GmailAppMengirim dan membaca emailGmailApp.sendEmail(to, sub, body)
ScriptAppMengelola trigger dan deploymentScriptApp.newTrigger(nama)
LoggerMencatat hasil ke log eksekusiLogger.log(nilai)

Contoh menulis satu baris log ke Spreadsheet yang terikat pada skrip:

function catatAgenda() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  sheet.appendRow([new Date(), "SM-001", "Surat Undangan", "Diterima"]);
}

j. Penanganan galat: try / catch

Mencegah skrip berhenti total bila ada masalah, misalnya ID folder salah atau file tidak ditemukan. Pesan galat dicatat agar mudah dilacak.

function bukaFolderAman() {
  try {
    const folder = DriveApp.getFolderById("ID_FOLDER");
    Logger.log("Folder: " + folder.getName());
  } catch (e) {
    Logger.log("Gagal membuka folder: " + e.message);
  }
}

Contoh gabungan: membaca isi folder

Menggabungkan variabel, perulangan, template literal, dan DriveApp. Ganti ID_FOLDER dengan ID folder uji coba (bagian akhir tautan folder di Drive).

function daftarFile() {
  const folder = DriveApp.getFolderById("ID_FOLDER");
  const files = folder.getFiles();
  while (files.hasNext()) {
    const f = files.next();
    Logger.log(`${f.getName()} | ${f.getDateCreated()}`);
  }
}

2. Trigger

Trigger menjalankan fungsi secara otomatis. Tiga jenis yang dipakai sepanjang mata kuliah: onFormSubmit (sesi 2), time-driven (sesi 7), dan doGet/doPost untuk Web App (sesi 5).

// Membuat trigger terjadwal lewat kode (jalankan sekali)
function buatTriggerHarian() {
  ScriptApp.newTrigger("latihan1")
    .timeBased()
    .everyDays(1)
    .atHour(7)
    .create();
}

// Menampilkan semua trigger yang aktif
function cekTrigger() {
  ScriptApp.getProjectTriggers().forEach(function (t) {
    Logger.log(t.getHandlerFunction() + " — " + t.getEventType());
  });
}
Catatan: hapus trigger uji coba setelah latihan (ScriptApp.deleteTrigger() atau menu Pemicu) agar tidak berjalan terus.

3. Pemetaan siklus hidup dokumen ke GAS

Siklus hidup dokumen menjadi kerangka seluruh mata kuliah. Tiap tahap punya layanan GAS yang mengotomasinya:

Tahap siklusContoh otomasiLayanan / fungsi GASSesi

4. Proyek akhir & studi kasus

Proyek akhir (UAS, 30%) adalah satu sistem manajemen dokumen digital yang mengintegrasikan seluruh tahap di atas. Studi kasus dipilih sekarang karena setiap sesi berikutnya akan dikerjakan pada kasus yang sama.

  • Pilih organisasi atau unit nyata (kantor, sekolah, UMKM, organisasi kampus) atau skenario realistis.
  • Tentukan 1–2 jenis dokumen utama yang paling sering diproses, misalnya surat masuk/keluar, kontrak, atau laporan.
  • Pastikan alur dokumennya cukup kaya untuk melewati semua tahap siklus.

Tugas Praktikum Sesi 1

Dikerjakan berkelompok, dikumpulkan sebelum sesi 2.

  1. Latihan kode. Modifikasi latihan1 atau daftarFile agar menampilkan data dari studi kasus kelompok Anda. Kumpulkan tautan proyek GAS.
  2. Tabel pemetaan. Untuk setiap tahap siklus dokumen, tulis kondisi saat ini di organisasi studi kasus, masalahnya, dan layanan GAS yang akan dipakai.
  3. Proposal studi kasus (maksimal 1 halaman). Isi nama organisasi, jenis dokumen, alur dokumen singkat, anggota kelompok, dan tahap yang dianggap paling menantang.
