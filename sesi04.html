Penamaan & Struktur Penyimpanan

Menerapkan konvensi penamaan file dan struktur folder arsip yang terbentuk otomatis, sehingga setiap dokumen punya nama yang seragam dan tersimpan di tempat yang tepat.

Metode
Praktikum lab, live coding
Bobot tugas
10%
A

Tujuan Pembelajaran

Setelah sesi ini, Anda mampu menerapkan penamaan file dan struktur penyimpanan dokumen secara otomatis.

  1. Menjelaskan prinsip konvensi penamaan file dan struktur folder arsip yang baik.
  2. Merancang konvensi penamaan dan struktur folder untuk studi kasus kelompok Anda.
  3. Menulis fungsi yang membentuk nama file otomatis dengan file.setName() dan Utilities.formatDate().
  4. Membuat folder tahun dan kategori secara otomatis dengan createFolder() tanpa menghasilkan folder ganda.

Prasyarat: skrip penerimaan dan klasifikasi dari sesi 2 dan 3 sudah berjalan, karena sesi ini memperluas skrip tersebut.

C

Materi Pembelajaran

1. Konvensi penamaan file

Konvensi penamaan adalah aturan baku untuk memberi nama file. Tanpa aturan, folder penuh nama seperti surat scan final (2) revisi.pdf, yang tidak bisa diurutkan, sulit dicari, dan tidak menjelaskan isinya. Dengan aturan yang sama untuk semua orang, nama file sudah memberi tahu isi dokumennya.

Prinsip nama file yang baik

PrinsipArtinyaContoh
InformatifMemuat unsur yang menjelaskan dokumen: unit, jenis, tanggal, nomorSEK_UND_20261112_UM-001.pdf
KonsistenPola yang sama untuk semua dokumenSelalu urutan unit, jenis, tanggal, nomor
Mudah diurutkanTanggal ditulis yyyyMMdd (tahun, bulan, hari) agar urutan abjad sama dengan urutan waktu20261112 (bukan 12-11-2026)
Aman dipakaiTanpa spasi dan karakter khusus; pemisah memakai garis bawah _Hindari / \ : * ? "
RingkasSingkatan baku untuk unit dan jenis dokumenUND = Undangan
Tidak membocorkan data sensitifNama file ikut terlihat saat dokumen dibagikanHindari nomor KTP atau gaji pada nama file

Pola yang dipakai di praktikum

Pola mengikuti RPS: [Unit]_[JenisDok]_[Tanggal]_[NomorUrut]. Nomor urut memakai kode arsip dari sesi 3 (misalnya UM-001), yang sudah unik untuk setiap dokumen. Hasilnya:

SEK_UND_20261112_UM-001.pdf
SEK_PMH_20261113_KP-004.pdf

2. Struktur folder arsip

Struktur folder adalah hierarki tempat dokumen disimpan. Di lemari arsip, ia seperti urutan lemari, laci, dan map. Struktur yang baik mengikuti skema klasifikasi dari sesi 3 dan membatasi kedalaman agar tidak membingungkan.

Arsip Surat Masuk
 └─ 2026
     ├─ Umum
     ├─ Kepegawaian
     ├─ Keuangan
     └─ Akademik
  • Maksimal 3–4 tingkat. Struktur yang terlalu dalam menyulitkan pencarian.
  • Pembagi pertama berdasarkan waktu (tahun) agar arsip lama mudah diperiksa masa retensinya di sesi 7.
  • Pembagi berikutnya berdasarkan skema klasifikasi dari sesi 3.
  • Folder dibuat otomatis saat dibutuhkan, tetapi hanya jika belum ada, supaya tidak muncul folder ganda.

Perbedaan penting: DriveApp.createFolder(nama) membuat folder di akar My Drive, bukan di folder arsip Anda. Untuk membuat folder di dalam folder tertentu, panggil induk.createFolder(nama) dari folder induknya.

Ekstensi file. setName() mengganti seluruh nama, termasuk bagian .pdf. Karena itu skrip harus mengambil ekstensi dari nama lama, lalu menyambungkannya kembali ke nama baru.

4. Praktikum: memperluas skrip sesi 3

Langkah 1. Uji fungsi penamaan lebih dulu

Fungsi penamaan tidak butuh Form, sehingga bisa diuji langsung. Tempel dua fungsi berikut ke editor skrip, lalu jalankan ujiPenamaan dan lihat hasilnya di log.

const KODE_UNIT = "SEK";   // ganti dengan kode unit studi kasus Anda

const SINGKATAN_JENIS = {
  "Undangan": "UND",
  "Permohonan": "PMH",
  "Pemberitahuan": "PBT",
  "Lainnya": "LNN"
};

// Membuat nama file baru dengan mempertahankan ekstensi
function buatNamaFile(namaLama, jenis, nomorArsip, tanggal) {
  const titik = namaLama.lastIndexOf(".");
  const ekstensi = titik === -1 ? "" : namaLama.substring(titik);   // mis. ".pdf"
  const singkatan = SINGKATAN_JENIS[jenis] || "LNN";
  const tgl = Utilities.formatDate(tanggal, "Asia/Jakarta", "yyyyMMdd");
  return KODE_UNIT + "_" + singkatan + "_" + tgl + "_" + nomorArsip + ekstensi;
}

function ujiPenamaan() {
  Logger.log(buatNamaFile("scan final (2).pdf", "Undangan", "UM-001", new Date()));
  // hasil: SEK_UND_20261112_UM-001.pdf (tanggal sesuai hari ini)
}

Langkah 2. Tambahkan fungsi "ambil atau buat folder"

Fungsi ini menggantikan ambilSubfolder dari sesi 3. Ia mencari folder bernama tertentu; bila ada, dipakai, dan bila belum ada, dibuat.

function ambilAtauBuatFolder(induk, nama) {
  const hasil = induk.getFoldersByName(nama);
  if (hasil.hasNext()) {
    return hasil.next();
  }
  return induk.createFolder(nama);
}

Langkah 3. Perbarui kolom Sheets

Tambahkan satu kolom lagi di akhir lembar Agenda berjudul Nama File, sehingga kolom terakhir menjadi: ... Tautan File, Kategori, Kode Arsip, Nama File.

Langkah 4. Perbarui fungsi utama

Ganti catatSuratMasuk dengan versi berikut. Fungsi ambilJawaban, nomorUrutBerikut, konstanta SKEMA, ID_SPREADSHEET, dan ID_FOLDER_ARSIP dari sesi 3 tetap dipakai tanpa perubahan.

function catatSuratMasuk(e) {
  const jawaban = ambilJawaban(e.response);
  const sekarang = new Date();

  // 1. Klasifikasi (dari sesi 3)
  const kategori = jawaban["Kategori Surat"];
  const kode = SKEMA[kategori];
  if (!kode) {
    throw new Error("Kategori tidak ada di skema: " + kategori);
  }
  const nomorArsip = kode + "-" + String(nomorUrutBerikut(kode)).padStart(3, "0");

  // 2. Susun folder tujuan: Arsip -> Tahun -> Kategori
  const file = DriveApp.getFileById(jawaban["Unggah File Surat"][0]);
  const tahun = Utilities.formatDate(sekarang, "Asia/Jakarta", "yyyy");
  const folderTahun = ambilAtauBuatFolder(DriveApp.getFolderById(ID_FOLDER_ARSIP), tahun);
  const folderKategori = ambilAtauBuatFolder(folderTahun, kategori);
  file.moveTo(folderKategori);

  // 3. Beri nama baru sesuai konvensi
  file.setName(buatNamaFile(file.getName(), jawaban["Jenis Surat"], nomorArsip, sekarang));

  // 4. Isi metadata pada deskripsi file (dari sesi 3)
  file.setDescription(
    "Kode arsip: " + nomorArsip +
    " | Kategori: " + kategori +
    " | Pengirim: " + jawaban["Pengirim"] +
    " | Perihal: " + jawaban["Perihal"]
  );

  // 5. Catat ke buku agenda
  const sheet = SpreadsheetApp.openById(ID_SPREADSHEET).getSheetByName("Agenda");
  const nomorAgenda = "SM-" + String(sheet.getLastRow()).padStart(3, "0");
  sheet.appendRow([
    nomorAgenda,
    sekarang,
    jawaban["Nomor Surat"],
    jawaban["Pengirim"],
    jawaban["Perihal"],
    jawaban["Jenis Surat"],
    file.getUrl(),
    kategori,
    nomorArsip,
    file.getName()
  ]);
}

Alurnya: kategori diubah menjadi kode dan nomor arsip, folder tahun dan kategori disiapkan, file dipindahkan, diberi nama baru, diberi deskripsi, lalu dicatat di Sheets.

Langkah 5. Uji dan periksa

  1. Jalankan ujiCoba() dari sesi 2 atau kirim Form sungguhan, minimal tiga kali dengan kategori berbeda dan satu kategori diulang.
  2. Di Drive, pastikan struktur folder Arsip → tahun → kategori terbentuk dan nama file mengikuti pola.
  3. Kirim dua dokumen dengan kategori yang sama dan pastikan tidak ada folder ganda.
  4. Di Sheets, pastikan kolom Nama File berisi nama baru.
Catatan: bila dua Form masuk pada detik yang sama, folder ganda masih mungkin terbentuk. Pada sistem sungguhan, hal ini dicegah dengan LockService. Untuk latihan ini, cukup periksa dan hapus folder ganda secara manual bila muncul.

Tugas Praktikum Sesi 4

Konvensi dan struktur folder dirancang bersama kelompok, sedangkan skripnya dikerjakan berpasangan. Semuanya dikumpulkan sebelum sesi 5.

  1. Rancang konvensi penamaan dan struktur folder studi kasus kelompok. Tuliskan pola nama, arti tiap unsur, daftar singkatan, lima contoh nama file, dan bagan struktur folder (maksimal empat tingkat).
  2. Terapkan rancangan tersebut pada skrip sesi 3: nama file otomatis dan folder tahun serta kategori yang dibuat otomatis tanpa duplikat.
  3. Uji dengan minimal tiga dokumen pada tiga kategori berbeda dan dua dokumen pada kategori yang sama. Hapus baris uji dan jalankan resetCounter() sebelum mengumpulkan.
  4. Perbarui laporan progres kelompok: ubah status tahap Penamaan & penyimpanan, lalu tulis kendala dan rencana sesi berikutnya.
  5. Kumpulkan: dokumen konvensi dan struktur folder, tautan Form, Spreadsheet (akses lihat), dan proyek skrip, tangkapan layar struktur folder serta daftar nama file di Drive, dan laporan progres terbaru.
